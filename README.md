# 🎵 Music Player Web App

A feature-rich, sleek, and responsive web-based music streaming app powered by JavaScript and external APIs. Search your favorite tracks, view lyrics, download in high quality, and listen seamlessly!

## 🔥 Features

* 🔍 **Search Songs**: Instantly search across thousands of tracks and artists.
* 🎧 **Interactive Audio Player**: Mini-player and Full-screen player with progress tracking.
* 📜 **Live Lyrics**: Fetch and read lyrics directly while listening.
* ⬇️ **High-Quality Downloads**: Download songs in your preferred audio quality.
* ❤️ **Favorites List**: Save your top tracks for quick access anytime.
* 💡 **Smart Recommendations**: Dynamic song suggestions based on the currently playing track.
* 📱 **Fully Responsive**: Beautiful UI tailored for both Desktop and Mobile devices.
